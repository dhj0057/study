AI Smart Help Desk · 처음 30분 시작 안내

처음에는 프로젝트를 열고, 본인 작업 한 개를 찾고, 도움을 요청하는 방법까지 익히면 됩니다. 코딩이나 Linear 사용 경험이 없어도 이 순서대로 진행할 수 있습니다. 팀장 도형준이 A 역할과 전체 통합을 맡고, B\~E는 팀원과 상의해 배정합니다.

우리 프로젝트: AI Smart Help Desk · 문의하지마세요 · 10/29 시작

일정: 외부 마감 2026년 12월 2일 / 팀 내부 최종 제출 12월 1일 21:00 / 기능 동결 11월 24일. 외부 제출 시각과 발표일은 공지 확인 기준입니다.

이 시작 과정에서는 유료 결제나 API 키 입력을 진행하지 않습니다. 계정에서 플러그인을 사용할 수 없다면 아래의 ‘본문 복사 방법’으로 참여하면 됩니다. 이 문서는 설치와 연결을 안내하며, 팀원 계정의 설치가 이미 완료되었다는 뜻은 아닙니다.

이후 B·C의 실제 모델 연결에 필요한 API 키는 도형준과 발급·관리 방식을 정합니다. 키 값은 채팅·Linear 댓글·캡처로 공유하지 않습니다.

0\~5분 · Linear에 가입하고 우리 프로젝트만 열기

도형준에게 받은 팀 초대 링크를 엽니다. 초대를 받지 않았다면 먼저 초대를 요청합니다.

본인이 사용할 계정으로 가입하거나 로그인하고 초대를 수락합니다. 계정이 있다는 것과 팀 프로젝트에 접근할 수 있다는 것은 별개입니다.

위의 우리 프로젝트 링크를 엽니다. 화면의 프로젝트 이름이 AI Smart Help Desk · 문의하지마세요 · 10/29 시작인지 확인합니다.

프로젝트 설명과 작업 목록을 읽습니다. 지금은 상태·담당자·마감일을 바꾸지 않습니다.

Linear의 이슈(issue)는 ‘해야 할 일 한 개’입니다. B\~E의 큰 역할 아래에 T03, T04 같은 개별 작업이 있습니다. 처음에는 큰 역할 전체를 끝내려 하지 않고, 배정받은 개별 작업 한 개를 진행합니다. 다른 프로젝트의 작업은 건드리지 않습니다.

프로젝트가 보이지 않으면 새 프로젝트를 만들지 말고 도형준에게 ‘가입한 계정 이름’과 ‘우리 프로젝트가 열리지 않는 상황’을 알려주세요.

5\~12분 · ChatGPT 또는 Codex에 Linear 연결하기

본인이 사용 가능한 ChatGPT 또는 Codex 화면에서 진행합니다. 공식 기본 절차는 Plugins → 검색 → 상세 → 설치 → 연결입니다. 공식 Plugins 안내

Plugins 탭을 엽니다.

검색창에서 Linear를 찾습니다.

Linear 플러그인의 상세 화면을 열고 설치 버튼을 선택합니다. 공식 안내에서는 더하기(+) 버튼으로 표시됩니다.

연결 안내가 나오면 본인의 Linear 계정으로 로그인합니다. 방금 초대를 수락한 계정과 같은지 확인합니다.

요청되는 연결 권한과 대상 계정을 확인하고 연결을 마칩니다. 설치할 때 연결 안내가 없으면 처음 사용할 때 나타날 수 있습니다.

새 채팅을 열고 아래 ‘복사할 질문 1’을 보냅니다. 설치한 플러그인의 기능은 새 채팅에서 사용할 수 있습니다. 설치·연결 공식 절차

설치 메뉴가 없거나 계정에서 사용이 제한되면 결제나 별도 API 키 발급으로 해결하지 않습니다. 화면에 나온 문구를 기록하고 아래 본문 복사 방법으로 진행합니다. 제공되는 기능은 계정·작업 공간에 따라 다를 수 있습니다.

Linear 플러그인으로 할 수 있는 일: 접근 권한이 있는 이슈를 읽고, 요청한 범위에서 설명·상태·기록 등을 관리하는 일입니다. 실제 코드 수정을 하려면 별도로 프로젝트 코드가 있는 로컬 폴더나 공유 저장소가 작업 환경에 연결되어 있어야 합니다. Linear 연결만으로 팀 코드 폴더가 자동으로 생기지는 않습니다.

코드 작업을 맡은 뒤 · GitHub 추가 연결

AI에게 GitHub 이슈·PR·저장소 조회를 맡길 때 선택적으로 연결합니다. 팀 저장소를 받은 로컬 폴더가 준비되어 있다면 GitHub 플러그인 연결 없이도 코드 작업을 시작할 수 있습니다.

도형준이 실제 팀 저장소 주소와 초대를 공유한 뒤 진행합니다.

본인 GitHub 계정으로 저장소 초대를 수락하고, 브라우저에서 팀 저장소가 열리는지 확인합니다.

AI 도구의 Plugins에서 GitHub를 검색해 설치하고 본인 GitHub 계정으로 연결합니다.

연결 대상에 팀 저장소가 포함되어 있는지 확인합니다. 권한이 없으면 도형준에게 저장소 접근을 요청합니다.

AI에게 “팀 저장소 [실제 주소]에 접근 가능한지 읽기만 확인하고, 현재 작업 폴더가 그 저장소인지 확인해줘”라고 요청합니다.

로컬에서 코드를 수정·실행할 도구라면 팀 저장소를 내려받은 폴더를 작업 공간으로 엽니다. 저장소 연결과 로컬 폴더 연결은 각각 확인합니다.

GitHub 연결만으로 로컬 실행 환경이 준비되는 것은 아닙니다. 폴더가 없거나 실행 방법이 불명확하면 README와 설치 순서를 도형준에게 확인합니다. 지금은 임의의 저장소나 다른 수업 폴더로 대신하지 않습니다. 설치 방식은 Linear와 같은 공식 Plugins 절차를 따릅니다.

없으면 폴더·저장소 연결에 무엇이 필요한지 물어보고, 코드를 이미 수정했다고 말하지 마.
코드 수정은 내가 연결한 팀 프로젝트 코드와 이 이슈 범위에서만 해줘.
공통 데이터 형식이나 다른 담당자의 모듈을 임의로 바꾸지 마.

실제로 확인한 결과와 아직 확인하지 않은 부분을 구분해줘.
다른 프로젝트·다른 사람의 이슈·담당자·마감일은 변경하지 마.
검증과 다른 팀원의 확인 전에는 Done으로 바꾸지 마.



첫 결과는 작아도 괜찮습니다. FAQ 초안, 가상 문의와 예상 결과, 화면 캡처, 실제 호출 기록, 코드 변경과 실행 결과 중 본인 이슈에 맞는 한 가지를 남깁니다. 작업 전체가 끝나지 않았다면 진행 내용을 기록하고 다음 할 일을 적습니다.

AI 답변은 작업을 돕는 초안입니다. 본인이 실제 파일을 열거나 화면을 실행해 이슈의 완료 조건을 확인합니다. 실행하지 않은 결과를 성공했다고 적지 않습니다.

목표·기한·선행 작업·할 일·완료 조건을 복사합니다.

일반 AI 채팅에 위 ‘질문 2’와 이슈 본문을 함께 붙입니다. “Linear에 직접 연결되어 있지 않으니 붙인 본문만 근거로 도와줘”라고 덧붙입니다.

AI가 제안한 결과를 직접 확인하고, 진행 기록과 증거는 본인이 Linear에 옮깁니다.

프로젝트 초대 자체가 안 되었다면 도형준에게 배정할 이슈 본문을 공유해 달라고 요청합니다. API 키·계정 비밀번호·다른 프로젝트 자료를 AI 채팅에 붙일 필요는 없습니다.

첫날 완료 확인 · 다섯 개

본인 Linear 계정으로 우리 프로젝트를 열었다. 접근이 막히면 계정 이름과 상황을 도형준에게 알렸다.

Linear 읽기 테스트를 했거나, 사용할 수 없어 본문 복사 방법으로 진행하기로 정했다.

도형준에게 실명·희망 역할 B\~E·가능 시간·도움이 필요한 부분을 전달했다.

배정된 이슈 한 개의 목표·마감·선행 작업·완료 조건을 확인했다. 배정 전이면 배정 요청을 남겼다.

작은 산출물과 실제 확인 결과를 남겼거나, 막힌 단계와 필요한 도움을 구체적으로 보고했다.

첫날 모든 작업을 Done으로 만들 필요는 없습니다. 결과물이 완료 조건을 충족한 경우에만 검토를 신청합니다.
